# 簡敬倫｜角色之外，創作之中

期中個人網站，以 HTML、CSS、原生 JavaScript 製作，無套件依賴。

## 開啟網站

直接使用瀏覽器開啟 `index.html` 即可。若已安裝 Node.js，也能執行 `node preview.cjs`，瀏覽 `http://127.0.0.1:4173`；按 Ctrl+C 停止。

## 網站內容與功能

- 五個單頁區塊：首頁、關於我、興趣與技能、作品集、未來與聯絡。
- 電腦與手機排版、手機折疊導覽、區塊導覽狀態。
- 五件作品與分類篩選；作品及攝影圖片可放大，按 Esc 關閉。
- 電子郵件按鈕使用 mailto，需訪客裝置有郵件應用程式；無後端寄信服務。
- 支援鍵盤操作、圖片替代文字與減少動態效果設定。
- 背景細網格、光暈漂移、SVG 光線與節點、首頁圓環與圖片動態。右下角可暫停／恢復，偏好保存在訪客本機瀏覽器；系統設定減少動態效果時停用動畫。
- 咖啡小遊戲藏在興趣區「音樂 × 咖啡」的小咖啡圖示中，點擊才開啟，沒有額外入口或操作宣傳。遊戲內研磨四次，開始注水、再次點擊停止，水量介於 180–220 ml 時可萃取完成。過量或不足皆可重新注水。
- 頁尾標語旁藏有小型正八面體，可用滑鼠、手指拖曳或方向鍵旋轉；不顯示操作提示。僅在操作時重新繪圖。

## 檔案

- `index.html`：內容、區塊、圖片來源與連結。
- `styles.css`：配色、版面與手機版（760px 以下）。
- `script.js`：手機導覽、區塊狀態、圖片預覽與作品分類。
- `easter-eggs.css`、`easter-eggs.js`：煮咖啡彩蛋的樣式與狀態流程，以及正八面體的拖曳操作與數學投影。
- `assets/web/`：網站實際使用的 11 張縮圖，保留原圖內容、縮小尺寸並轉成 JPEG。
- `assets/images/`：使用者提供的原始圖片，未修改。
- `prepare-images.ps1`：Windows PowerShell 圖片轉檔腳本；已產生網頁用圖片，瀏覽網站不需執行。
- `AI協作紀錄.md`：目前的 AI 協作與待本人完成的檢視項目。

- 圖示與裝飾：CSS、文字符號及自製 SVG favicon。未使用 AI 生成圖片，未載入外部字體或追蹤服務。

## GitHub 繳交

此輪僅完成本機網站，尚未建立儲存庫、上傳或部署。

將 `index.html`、兩份 CSS、兩份 JavaScript、`assets/`、`README.md` 與 `AI協作紀錄.md` 保留資料夾結構上傳至作業儲存庫。原圖請先確認可公開；網站運作僅需要 `assets/web/` 與 `assets/favicon.svg`。檢查用的 `素材預覽.jpg` 不需上傳。

如需 GitHub Pages，可在儲存庫 Settings → Pages 選擇從分支發布，再選 `main` 與根目錄。實際設定依 GitHub 介面為準。
